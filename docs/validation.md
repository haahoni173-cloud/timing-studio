## 驗證界線

PNG 圖片剪貼簿已驗證；這次未自動操作 PowerPoint 應用程式進行貼上驗證。GitHub Pages 工作流程已備妥，尚未在使用者的 GitHub 帳號上執行部署。

WebMCP 是漸進式附加介面，提供讀取圖檔與新增數位訊號。一般編輯與圖片輸出不依賴它。本機 Chrome 未提供正式 WebMCP 連線，因此無法驗證原生 WebMCP 登錄。

可用 `tests/browser.cjs` 與 `tests/interface.cjs` 重現瀏覽器驗證，輸出的測試圖檔與畫面位於忽略追蹤的 `output` 目錄。
