# 操作說明

## 選單與設定位置

- **File**：新增圖檔、Import 匯入、儲存圖檔、Export 匯出。
- **Edit**：復原／重做、複製／貼上／刪除，以及選取、切換、H／L／X／Z 工具。
- **Setting → Diagram**：全活頁的時間軸、間距與波形粗細。
- **Setting → 快捷鍵／語言**：自訂按鍵與繁體中文／英文介面。這些偏好保存在目前瀏覽器，不會修改使用者輸入的名稱或標註。

上方圖示列提供參考線、時間箭頭、文字、復原／重做、吸附、格線與縮放。滑鼠停留會顯示名稱與目前快捷鍵。

## 畫一般數位波形

1. 左側按「新增訊號」，右側修改訊號名稱。
2. 在 Edit 選擇「切換電位」，點擊時間格子即可翻轉高低電位。
3. 要連續繪製時，選 H、L、X 或 Z，再沿著訊號拖曳。
4. 或展開右側「快速建立波形」，在「波形序列」輸入 `0011110000`，按「套用波形序列」。每個字元對應目前的格線間隔，最後一個狀態會延伸到時間軸末端。

波形序列重新建立整條訊號。若切換邊緣不在格線上，序列欄位會留空，以免用格子文字近似原本的細部時間。

## 活頁與側欄

畫布底部的分頁像 Excel 活頁，每次顯示一頁。按「＋」新增，雙擊分頁可命名；「活頁設定」提供 1–32 頁的數量設定，以及複製／刪除目前活頁。每頁保留自己的波形、標註與縮放視野，新活頁繼承目前 Diagram 設定。

「儲存」下載整份活頁圖檔；複製圖片與下載 PNG／SVG 則輸出目前活頁。刪除活頁、減少頁數與修改圖形都能用復原還原。

拖動左側訊號的 ⋮⋮ 把手上下排序，波形與跟隨該列的標註同步更新。左右欄位與畫布間的細邊界可拖曳調整寬度。

右側「⇒」收合屬性，上方「⇐」展開。也可先點選訊號，再按 Q 切換。收合後單純選取訊號不會強制展開；新增文字時則展開以便輸入內容。

點擊屬性區塊的標題可展開／收合，程式會記住區塊狀態。訊號排序使用左側拖曳，複製／貼上／刪除使用快捷鍵或 Edit，右側集中顯示物件設定。

## 緊湊顯示

在 Setting → Diagram 設定訊號列高，範圍為 24–128 px；可輸入數值、拖動滑桿，或選擇極緊湊／緊湊／標準。

波形高度可另調整為 8–64 px，但至少保留 8 px 的列間距。縮小列高時，超出可用範圍的波形高度會一起縮小，避免波形重疊。

按「套用所有活頁」才修改圖形；取消不會改變資料。時間長度、單位、格線間隔、預設列高、波形高度與全域波形粗細會一起套用所有活頁。縮短時間軸會提示裁切，整次操作可用 Ctrl+Z 還原。

## 個別粗細與列高鎖定

選取訊號後，在右側「線條樣式」設定粗細，展開「個別列高與鎖定」設定該訊號的列高。

- 勾選「鎖定粗細」：之後套用 Diagram 時，保留此訊號的粗細。
- 勾選「鎖定列高」：保留此訊號的列高；若沒有個別值，鎖定時會記住目前實際列高。
- 未鎖定的粗細與列高，在下次套用 Diagram 時會更新為全域值。解除鎖定後也依此規則更新。

兩項可分別鎖定；鎖定期間仍能在右側手動修改。若個別列比較矮，波形高度會自動限制在該列內。鎖定與個別設定會存入圖檔。

## 複製與貼上訊號

選取整條訊號後按 Ctrl+C，再選取貼上位置並按 Ctrl+V。新訊號會插在選取訊號下方；沒有選取訊號時接在末端。可切換到另一活頁貼上。

複製包含波形、顏色、粗細、線條樣式、觸發箭頭、個別列高與鎖定；標註保留在原位置，不隨訊號複製。貼到較短的時間軸時會裁掉範圍外邊緣；每頁上限 64 條。

Del 刪除目前選取物件；若選取的是切換邊緣，僅刪除選取邊緣。輸入欄位內的 Ctrl+C／Ctrl+V／Del 保留一般文字編輯操作。

## 畫時脈

左側的時脈按鈕可新增時脈，也可以選取既有訊號後按「將此訊號設為時脈」。

設定週期、占空比、起始時間與閒置電位。起始時間之前保持閒置電位；到達起始時間時切換，並重複至時間軸末端。占空比代表一個週期中的高電位比例。

## 調整時間與對齊

切換至「選取」，拖曳波形的上升或下降邊緣。開啟格線吸附時，邊緣會吸附至格線，也會靠齊附近的其他訊號邊緣。按住 Alt 可暫時自由拖曳。

Shift 點選多個邊緣後，可整組拖曳，或用左右方向鍵移動一格。Alt 配合左右方向鍵可移動 0.1 單位。

要讓不同訊號的邊緣發生在同一時間：

1. 使用 Shift，在各訊號選取一個切換邊緣。
2. 右側「對齊到時間」輸入目標時間。
3. 按「對齊選取邊緣」。

同一訊號的多個切換邊緣不能重疊；對齊若會跨越相鄰邊緣，程式會保留原圖並提示。多選時修改線條樣式，會套用至所選邊緣所屬的訊號。

## 線條與標註

選取訊號或標註後，右側設定顏色、0.5–8 px 粗細、實線／虛線／點線，以及起點／終點箭頭。

- **參考線**：選工具後點擊時間位置。拖動頂端圓點或上方標籤調整時間，避免阻擋底下的波形邊緣。
- **時間箭頭**：選工具後，從起點拖曳至終點。預設文字顯示時間差，也可改成 `t_setup` 等名稱。選取後可拖兩端控制點，或整組平移。
- 時間箭頭屬性中「顯示標註文字」與「顯示時間差」分別控制名稱與數值。兩項皆開啟時，例如顯示 `t_setup (2 ns)`；兩項關閉時只保留箭頭，原文字不會被刪除。
- **文字**：選工具後點擊位置，接著在右側輸入文字。可拖曳或在右側修改時間與垂直位置。

## 觸發箭頭

選取訊號，在「整條訊號觸發箭頭」選擇不顯示、Pos 上升沿、Neg 下降沿，或兩者。

要指定單一事件，切換至選取工具並點擊切換邊緣，再於「選取邊緣的觸發箭頭」選擇依整條設定、顯示或隱藏。個別設定優先於整條設定，拖動切換時間時會一起保留。

0 → 1 的箭頭尖端向上，1 → 0 向下，直接疊在波形垂直切換線中央，使用波形本身作為箭身。X／Z 邊界不顯示觸發箭頭。輸出 PNG／SVG 或複製至 PPT 時會保留這些標記。

## 儲存與製作報告

File →「儲存圖檔」或 Ctrl+S 下載 `.timing.json`，保留所有活頁與可編輯內容。File → Import 的獨立視窗可選擇「取代整份圖檔」或「加入為新活頁」，支援舊版單頁圖檔。匯入上限 16 MB，加入後總頁數不得超過 32 頁。

瀏覽器會自動保存活頁、側欄、屬性區塊與偏好，但不同網址、瀏覽器與電腦的保存內容各自獨立。

File → Export 在獨立視窗選擇 PNG、SVG 或 TIMING.JSON。報告用圖片可設定白色或透明背景、PNG 輸出倍數，以及是否保留格線。PNG／SVG／複製圖片只輸出目前活頁，TIMING.JSON 包含整份活頁；PWL／CSV 留待後續加入。

按「複製圖片至 PPT」後，到 PowerPoint 按 Ctrl+V。若瀏覽器拒絕剪貼簿寫入，使用顯示的 PNG 下載按鈕，再把圖片拖入 PowerPoint。

PNG 適合固定報告外觀；SVG 可縮放，字型則依開啟電腦上的可用字型顯示。圖片中的波形要修改時，回到可編輯的圖檔重新輸出。

## 快捷鍵

| 快捷鍵 | 操作 |
| --- | --- |
| V | 選取工具 |
| B | 切換高低電位 |
| H／L／X／Z | 高電位／低電位／未知／高阻抗工具 |
| T | 新增文字工具 |
| R／D | 參考線／時間箭頭工具 |
| Q | 顯示／隱藏屬性 |
| F | 符合畫布 |
| Ctrl+C／Ctrl+V | 複製／貼上整條訊號 |
| Shift 點選邊緣 | 多選／取消選取 |
| Alt 拖曳 | 暫時關閉吸附 |
| 左右方向鍵 | 平移選取邊緣一格 |
| Delete | 刪除選取邊緣或物件 |
| Ctrl+Z | 復原 |
| Ctrl+Shift+Z | 重做 |
| Ctrl+S | 下載可編輯圖檔 |
| Escape | 取消拖曳並回到選取工具 |

在文字、名稱或數值欄位輸入時，H／L／X／Z／T／Q 不會觸發工具。分頁聚焦時，左右方向鍵切換活頁；側欄分隔線聚焦時，左右方向鍵調整欄寬。

上述為預設快捷鍵。在 Setting → 快捷鍵選取欄位後按下按鍵組合，再按「套用」。重複、無效或保留按鍵會提示；「恢復預設」先重設清單，再按「套用」生效。工具提示與操作說明會跟隨新按鍵更新。
